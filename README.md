# BarberFlow
Projeto acadêmico desenvolvido durante o curso da Unidade Curricular de Banco de Dados, com o objetivo de criar uma plataforma de gestão para pequenas e médias barbearias, utilizando uma aplicação web integrada a um banco de dados relacional.

## Estado do projeto

Primeira entrega da aplicação: backend com cadastro e consulta de barbearias, validação de dados e persistência no PostgreSQL. Os outros módulos e a interface React estão planejados.

| Diretório | Conteúdo |
| --- | --- |
| `backend/` | API Java 21/Spring Boot, migrações SQL, testes e roteiro de execução |
| `docs/` | Documentação sincronizada com o GitBook e anexos acadêmicos |

Comece pelo [guia de execução e estudo do backend](backend/README.md).

Documentação: [GitBook BarberFlow](https://a3-sistema-de-gerenciamento-de-b.gitbook.io/a3-sistema-de-gerenciamento-de-barbearia-docs/).

Os scripts acadêmicos originais são preservados em `docs/.gitbook/assets/`. A API utiliza um banco separado de desenvolvimento, conforme o guia.
