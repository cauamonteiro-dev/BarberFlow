# 05. Objetivos

## Objetivo geral

Desenvolver e demonstrar uma plataforma web integrada a banco de dados relacional para organizar a operação de barbearias, com agendamento e acesso conforme o perfil do usuário.

## Objetivos específicos e entregas

| Objetivo | Entrega implementada |
| --- | --- |
| Centralizar cadastros | Gestão de barbearias, clientes, vínculos, profissionais, serviços e planos |
| Organizar reservas | Agenda, cálculo do término, conflito de intervalos e cancelamento |
| Controlar disponibilidade | Expediente semanal, pausas, bloqueios e consulta diária de vagas |
| Diferenciar responsabilidades | Administrador geral, Barbearia, barbeiro e cliente |
| Preservar privacidade operacional | Autorização por unidade e identificação do cliente pela sessão |
| Controlar adesões | Assinaturas, períodos, situação e consulta de vigência |
| Apoiar decisões | Indicadores, comparação temporal, gráficos, detalhamento e CSV |
| Preservar informação histórica | Valor combinado, indicação de estimativas e conclusão do atendimento |
| Permitir uso móvel | Layout responsivo, navegação adaptada e temas claro/escuro |
| Demonstrar persistência | PostgreSQL local e hospedado, migrações e teste após reinício |
| Permitir reprodução | Inicializador local, testes, código versionado e instruções de operação |

As funcionalidades deliberadamente fora da entrega estão separadas em [limitações e melhorias futuras](19.-limitacoes-e-melhorias-futuras.md).
