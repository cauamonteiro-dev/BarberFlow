# 05. Objetivos

### Objetivo geral

Desenvolver uma plataforma de gestão para pequenas e médias barbearias capaz de centralizar e organizar informações de clientes, barbeiros, serviços, agendamentos, planos e assinaturas por meio de um banco de dados relacional.

### Objetivos específicos

* Centralizar informações das barbearias;
* Permitir o gerenciamento de clientes;
* Permitir o gerenciamento de barbeiros;
* Permitir o gerenciamento de serviços;
* Organizar os agendamentos;
* Verificar a disponibilidade dos barbeiros;
* Permitir o gerenciamento de planos e assinaturas;
* Relacionar os dados das diferentes operações;
* Disponibilizar consultas sobre os dados armazenados;
* Garantir a persistência e integridade das informações;
* Desenvolver uma aplicação integrada ao banco de dados.
