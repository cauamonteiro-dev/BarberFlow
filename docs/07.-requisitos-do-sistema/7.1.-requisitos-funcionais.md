# 7.1. Requisitos Funcionais

Todos os requisitos abaixo possuem implementação na versão de referência. A autorização descrita em cada perfil se aplica às operações correspondentes.

| ID | Requisito e critério de aceite |
| --- | --- |
| RF01 | Cadastrar clientes; na gestão de unidade, criar cliente e vínculo em uma transação. |
| RF02 | Consultar e alterar clientes autorizados; inativar o vínculo com a unidade, preservando histórico. Não há exclusão física de clientes pela interface. |
| RF03 | Cadastrar e alterar profissionais da própria unidade, com situação ativa/inativa. |
| RF04 | Cadastrar, consultar, alterar e inativar serviços, sem apagar reservas anteriores. |
| RF05 | Definir nome, preço não negativo e duração de 1 a 1.440 minutos para o serviço. |
| RF06 | Criar reservas vinculando unidade, cliente, profissional e serviço compatíveis. |
| RF07 | Validar expediente, bloqueios e conflitos antes de gravar um atendimento. |
| RF08 | Consultar, remarcar e mudar a situação de reservas conforme as regras de cada perfil. |
| RF09 | Gerenciar planos por unidade, com preço e situação. |
| RF10 | Registrar e alterar assinaturas vinculadas a cliente e plano da unidade. |
| RF11 | Controlar situação e período das assinaturas e informar a vigência por datas. |
| RF12 | Disponibilizar consultas dos registros autorizados. |
| RF13 | Relacionar clientes, unidades, profissionais, serviços, reservas, planos e assinaturas. |
| RF14 | Oferecer filtros temporais, agrupamentos, agregações e ordenações gerenciais. |
| RF15 | Cadastrar, consultar e alterar barbearias; a criação é exclusiva do administrador geral. |
| RF16 | Autenticar por e-mail/senha, identificar a sessão e permitir sair. |
| RF17 | Aplicar os quatro perfis e impedir acesso cruzado entre unidades ou clientes. |
| RF18 | Gerenciar acessos locais; somente o administrador geral concede gestão Barbearia. |
| RF19 | Configurar expediente semanal e bloqueios de cada profissional. |
| RF20 | Pesquisar unidades ativas pelo nome e abrir sua apresentação com descrição, fotos e endereço demonstrativos. |
| RF21 | Mostrar na página inicial do cliente suas reservas em todas as unidades, com filtros Próximos e Histórico. |
| RF22 | Consultar horários em intervalos de 15 minutos, informar carregamento/erro/ausência de vagas e permitir nova tentativa. |
| RF23 | Permitir ao cliente reservar, remarcar e cancelar somente seus atendimentos futuros em aberto. |
| RF24 | Identificar o barbeiro e mostrar sua agenda do dia, seleção de data e consulta da agenda autorizada. |
| RF25 | Permitir ao barbeiro confirmar e concluir atendimentos próprios, com conclusão a partir do início. |
| RF26 | Registrar valor combinado e indicação de estimativa; preservar o preço quando o catálogo muda. |
| RF27 | Apresentar faturamento de serviços concluídos e valor em aberto separadamente. |
| RF28 | Exibir dashboards com filtros por período, profissional e serviço e comparação temporal. |
| RF29 | Permitir interação com rankings, detalhamento de gráficos e exportação CSV do recorte visível. |
| RF30 | Exibir transição após login, nome do usuário/unidade e identidade visual adequada a cada área. |

As imagens, logos e endereços das unidades fictícias são definidos no frontend; não há editor de perfis comerciais ou upload de fotos pelo gestor nesta entrega.
