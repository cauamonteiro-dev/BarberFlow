# 7.1. Requisitos Funcionais

### RF01 — Gerenciamento de clientes

O sistema deve permitir cadastrar clientes.

### RF02 — Consulta e alteração de clientes

O sistema deve permitir consultar, alterar e excluir ou inativar clientes.

### RF03 — Gerenciamento de barbeiros

O sistema deve permitir cadastrar e gerenciar barbeiros vinculados às barbearias.

### RF04 — Gerenciamento de serviços

O sistema deve permitir cadastrar, consultar, alterar e controlar o status dos serviços.

### RF05 — Informações dos serviços

O sistema deve permitir definir preço e duração para cada serviço.

### RF06 — Agendamento

O sistema deve permitir realizar agendamentos vinculando cliente, barbeiro e serviço.

### RF07 — Verificação de disponibilidade

O sistema deve verificar a disponibilidade do barbeiro antes de registrar um agendamento.

### RF08 — Gerenciamento de agendamentos

O sistema deve permitir consultar e alterar os agendamentos.

### RF09 — Gerenciamento de planos

O sistema deve permitir cadastrar, consultar e alterar planos oferecidos pelas barbearias.

### RF10 — Gerenciamento de assinaturas

O sistema deve permitir registrar assinaturas vinculadas a clientes e planos.

### RF11 — Controle de assinaturas

O sistema deve permitir controlar o período e o status das assinaturas.

### RF12 — Consultas

O sistema deve disponibilizar consultas sobre os dados armazenados.

### RF13 — Relacionamento de informações

O sistema deve permitir consultas envolvendo dados relacionados de diferentes entidades.

### RF14 — Consultas gerenciais

O sistema deve permitir consultas utilizando filtros, agrupamentos, ordenações e funções de agregação quando aplicável.

### RF15 — Gerenciamento de barbearias

O sistema deve permitir cadastrar, consultar e alterar barbearias, incluindo o controle de sua situação ativa ou inativa.

Na primeira entrega do backend, estão implementados o cadastro e as consultas. A alteração e o controle posterior da situação permanecem previstos.
