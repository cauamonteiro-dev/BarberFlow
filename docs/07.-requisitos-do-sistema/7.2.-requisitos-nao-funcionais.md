# 7.2. Requisitos não Funcionais

### RNF01 — SGBD relacional

O sistema deverá utilizar um Sistema Gerenciador de Banco de Dados relacional.

### RNF02 — Integridade dos dados

O banco deverá utilizar chaves primárias, chaves estrangeiras e restrições de integridade.

### RNF03 — Persistência

Os dados cadastrados pela aplicação deverão ser persistidos no banco de dados.

### RNF04 — Integração

A aplicação deverá se comunicar com o banco de dados por meio do backend.

### RNF05 — Usabilidade

As principais funcionalidades deverão possuir uma interface compreensível para os usuários.

### RNF06 — Manutenibilidade

A aplicação deverá possuir uma estrutura organizada que facilite sua manutenção e evolução.

### RNF07 — Consistência

O sistema deverá evitar operações que resultem em dados incompatíveis com as regras de negócio definidas.
