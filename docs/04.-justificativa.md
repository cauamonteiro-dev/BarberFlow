# 04. Justificativa

## Justificativa

A centralização das informações é importante para melhorar a organização da operação das barbearias e reduzir problemas relacionados ao controle manual ou descentralizado dos dados.

O uso de um banco de dados relacional permitirá estruturar os relacionamentos entre clientes, barbearias, barbeiros, serviços, agendamentos, planos e assinaturas, proporcionando maior consistência das informações e facilitando sua consulta.

### Benefícios esperados

* Redução de conflitos de horários;
* Centralização das informações;
* Maior organização dos dados;
* Facilidade para consultar informações;
* Melhor acompanhamento dos clientes;
* Melhor controle das assinaturas;
* Facilitação do gerenciamento dos serviços e profissionais;
* Geração de informações para apoiar a gestão.

O projeto busca, portanto, utilizar a tecnologia para transformar informações descentralizadas em dados estruturados e relacionados.
