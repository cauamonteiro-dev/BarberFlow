# 02. Introdução

O BarberFlow é uma proposta de plataforma de gestão voltada para pequenas e médias barbearias.

O projeto busca centralizar informações relacionadas às barbearias, clientes, barbeiros, serviços, agendamentos, planos e assinaturas em uma estrutura integrada de banco de dados.

A proposta surge a partir da necessidade de reduzir a descentralização das informações e facilitar o gerenciamento da operação das barbearias.

O sistema será desenvolvido utilizando uma arquitetura composta por frontend, backend e banco de dados relacional, permitindo que as informações sejam armazenadas, relacionadas, consultadas e atualizadas de forma estruturada.

O BarberFlow será concebido como uma plataforma capaz de atender diferentes barbearias, mantendo os dados de cada estabelecimento organizados.
