# 02. Introdução

O BarberFlow é uma plataforma web acadêmica de gestão e agendamento para pequenas e médias barbearias. Centraliza estabelecimentos, clientes, profissionais, serviços, reservas, planos e assinaturas em um banco relacional.

O cliente encontra suas próprias reservas na página inicial e pesquisa os estabelecimentos em uma área separada. Pode conhecer a unidade, consultar serviços e horários e gerenciar suas reservas futuras. O barbeiro acompanha os atendimentos atribuídos a ele. A conta Barbearia administra somente a unidade autorizada, enquanto o administrador geral possui supervisão da plataforma.

A arquitetura reúne React no navegador, uma API REST em Java/Spring Boot e PostgreSQL. A API aplica autenticação, isolamento por unidade e validações transacionais; o banco mantém chaves, restrições e os registros persistentes.

A evolução do projeto acrescentou identidade visual, temas claro e escuro, adaptação para celulares, expediente por profissional, preservação de preços combinados e dashboards. A demonstração roda no Vercel com PostgreSQL no Neon. A migração preservou os dados e as contas da demonstração anterior. A seção de operação descreve a publicação e as condições dos planos gratuitos.

O foco acadêmico permanece a integração entre modelagem, SQL, integridade, transações e aplicação. Valores apresentados como faturamento representam serviços concluídos, sem comprovar recebimento financeiro.
