# 13. Povoamento do Banco de Dados

#### 13.1. Objetivo

Após a implementação da estrutura física, foi realizado o povoamento do banco de dados com informações fictícias.

O objetivo foi simular situações reais de utilização do BarberFlow, permitindo validar os relacionamentos entre as tabelas e preparar o ambiente para a execução de consultas SQL.

#### 13.2. Distribuição dos registros

Foram inseridos 200 registros, distribuídos entre as oito tabelas:

| Tabela             | Registros |
| ------------------ | --------- |
| Barbearias         | 5         |
| Clientes           | 35        |
| Cliente\_Barbearia | 50        |
| Barbeiros          | 15        |
| Serviços           | 25        |
| Planos             | 10        |
| Agendamentos       | 40        |
| Assinaturas        | 20        |
| Total              | 200       |

#### 13.3. Execução e validação

A inserção dos dados foi realizada por meio de um script SQL específico, respeitando a dependência entre as tabelas e seus relacionamentos.

Após a execução, foram realizadas consultas `SELECT` para verificar a presença dos registros e confirmar que a população inicial ocorreu corretamente.
