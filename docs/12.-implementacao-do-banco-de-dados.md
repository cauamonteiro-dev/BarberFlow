# 12. Implementação do Banco de Dados

#### 12.1. SGBD escolhido

O BarberFlow utiliza o PostgreSQL como Sistema Gerenciador de Banco de Dados (SGBD).

A escolha foi motivada pela confiabilidade, suporte a relacionamentos relacionais, integridade referencial e compatibilidade com a arquitetura planejada para o sistema.

O PostgreSQL permite trabalhar com chaves primárias, chaves estrangeiras, restrições e transações, oferecendo os recursos necessários para a estrutura de dados do projeto.

#### 12.2. Criação da estrutura física

A partir do modelo lógico desenvolvido anteriormente, foi realizada a implementação física do banco de dados.

Foram criadas oito tabelas:

1. `barbearia`
2. `cliente`
3. `cliente_barbearia`
4. `barbeiro`
5. `servico`
6. `agendamento`
7. `plano`
8. `assinatura`

Cada tabela possui atributos, tipos de dados e restrições definidos conforme sua finalidade e os relacionamentos estabelecidos na modelagem.

#### 12.3. Restrições e integridade

Durante a implementação, foram utilizadas restrições para preservar a consistência dos registros:

* `PRIMARY KEY`: identificação única dos registros.
* `FOREIGN KEY`: estabelecimento dos relacionamentos entre tabelas.
* `NOT NULL`: obrigatoriedade de preenchimento.
* `UNIQUE`: prevenção de valores duplicados em campos específicos.
* `CHECK`: validação de condições para determinados atributos.

Também foi implementada uma chave estrangeira composta no relacionamento entre agendamentos e vínculos de clientes com barbearias, reforçando a integridade dos dados.
